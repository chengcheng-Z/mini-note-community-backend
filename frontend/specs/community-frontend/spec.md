## 背景与动机

`xiaoHonShu` 后端已具备登录、用户、笔记、关注、对象存储、计数等能力，但目前没有可操作的界面。
本项目要交付一个**真正能使用**的 Web 前端：用户能登录、刷首页、看笔记、点赞、关注、发布内容、查看个人主页。

“真正能使用”的定义：

1. 默认连接真实后端，不依赖假数据。
2. 后端接口就绪后，只需改环境变量，不需要改业务代码。
3. 后端暂时不能启动时，开发期可用 mock 自测，但 mock 不得进入生产构建的默认路径。

## 目标

- 主目标：完成「登录 → 首页 feed → 笔记详情 → 点赞/关注 → 发布 → 我的」主链路。
- 次目标：移动端与桌面端都可用，具备加载态、空态、错误态。
- 次目标：核心逻辑有自动化测试，构建、类型检查、lint 全部通过。

## 非目标

- 不做商城、私信、评论、搜索推荐算法、管理后台。
- 不修改后端业务代码；后端缺口由用户按本 spec 的契约补齐。
- 不做原生 App、不做 SSR/SEO。
- 不做多语言、暗黑模式（后续可加）。

## 用户故事

- 作为游客，我想用手机号登录，以便看到内容和互动。
- 作为用户，我想在首页瀑布流里刷图文和视频笔记，以便发现内容。
- 作为用户，我想点开笔记看大图和视频，以便消费内容。
- 作为用户，我想点赞、取消点赞、关注作者，以便表达喜欢并订阅更新。
- 作为用户，我想上传图片或视频发布笔记，以便分享内容。
- 作为用户，我想在“我的”页面看到自己的信息和作品，以便管理账号。

## 验收标准

每条都可测试，对应 Phase 4 的测试用例。

### 认证

- AC-01 登录页只做手机号验证码登录（`type=1`）；发送验证码后按钮 180 秒倒计时，未注册手机号自动注册。
- AC-02 登录成功后保存 token，刷新页面仍保持登录；退出登录清空 token 并跳转登录页。
- AC-03 未登录访问受保护页面时跳转登录页；登录成功后回到原页面。

### 首页与详情

- AC-04 首页为双列瀑布流，首屏显示骨架屏，滑到底自动加载下一页，加载完显示“没有更多了”。
- AC-05 卡片展示封面、标题、作者头像昵称、点赞数；视频卡片显示时长角标。
- AC-06 图片懒加载；视频卡片在可见且用户开启预览时静音播放，离开可视区暂停。
- AC-07 详情页支持图文轮播与视频播放；返回后首页滚动位置不丢。
- AC-08 接口失败显示错误态和重试按钮；接口返回空列表显示空态。

### 互动

- AC-09 点赞/取消点赞采用乐观更新；请求失败回滚并提示；未登录先跳登录。
- AC-10 关注/取关采用乐观更新；详情页展示作者关注状态；未登录先跳登录。
- AC-11 点赞数在列表和详情保持一致；从详情返回列表后状态同步。

### 发布与我的

- AC-12 发布页支持选择图片（多张）或视频（单个），上传到 `/file/upload` 后调用 `/note/publish`。
- AC-13 上传显示进度；超过大小或类型限制时前端拦截并提示。
- AC-14 发布成功后回到首页并刷新列表（后端发布接口暂不返回笔记 ID）；失败保留已填内容并提示。
- AC-15 “我的”页展示当前用户信息、我的笔记列表，支持退出登录。

### 工程质量

- AC-16 所有请求走 `/api` 前缀（开发期 Vite 代理到 `http://localhost:8000`）。
- AC-17 请求自动携带 `Authorization: Bearer <token>`；登录失效统一清理并跳登录。
- AC-18 `VITE_USE_MOCK=false` 时页面不出现任何假数据。
- AC-19 `npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 全部通过。
- AC-20 375px 宽度与 1440px 宽度下主链路可用，无横向滚动。

## 约束与假设

- 技术栈：React 18 + Vite + TypeScript。
- 浏览器：Chrome/Edge 最近两个大版本、移动端 Safari。
- 后端当前无法本地完整启动，因此联调前以契约为准，开发期使用 mock。
- 后端需补齐以下能力，否则 AC-04、AC-09、AC-10、AC-15 无法真实验收：
  - feed 列表接口
  - 点赞、取消点赞、批量点赞状态接口
  - 当前用户信息接口
  - 关注状态接口
  - 网关路由与 CORS（或同源反向代理）
- 笔记类型：`0=图文`，`1=视频`；登录类型：`1=验证码`，`2=密码`。
- 后端统一响应结构：`{ success, message, errorCode, data }`；分页响应额外带 `pageNo/pageSize/totalCount/totalPage`。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 后端契约与实现不一致 | 页面无法真实使用 | 契约集中在 `design.md`，类型集中定义，联调时只改适配层 |
| 网关 `StripPrefix=1` 与控制器路径不匹配 | 除登录外接口 404 | 列入后端前置任务；提供冒烟脚本验证 |
| 网关未配置 CORS | 浏览器请求被拦 | 开发期 Vite 代理；生产用 nginx 同源代理 |
| 视频格式不统一 | 视频无法播放 | mp4 直接播放，m3u8 使用 hls.js，加载失败显示提示 |
| token 存在 localStorage | XSS 可窃取 | 不使用 `dangerouslySetInnerHTML`，不打印 token；后续可改 httpOnly cookie |
| 长列表卡顿 | 滑动不流畅 | 分页加载、图片懒加载、必要时引入虚拟列表 |
| 大文件上传失败 | 发布失败 | 前端限制大小与类型、显示进度、超时与重试提示 |
| 后端长期不可用 | 无法端到端验收 | 保留 mock 模式完成 UI 与逻辑验收，真实联调列为上线前置条件 |
